# iPod device image sources

The images in this directory are model-identification assets from Apple's official iPod identification page:

- https://support.apple.com/zh-cn/103823
- Apple CDN base: https://cdsassets.apple.com/live/7WUAS350/images/ipod/

The files cover iPod touch generations 1–7, iPod nano generations 1–7, iPod shuffle generations 1–4, iPod mini generations 1–2, and iPod classic generations 1–7 (including the fourth-generation color-display variant). Border-connected neutral webpage backgrounds were removed without altering device interiors. The catalogue was also cross-checked against https://macdb.cn/.
